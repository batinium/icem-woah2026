# Judge validation against gold labels (run 026)

Generated by `scripts/analyze_label_recovery_vs_gold.py` over
`026_label_recovery_judge/checkpoint.jsonl` (qwen3.5-9b, seed 17, 963 rows).
The datasets carry gold labels, so this requires no new human annotation.

## 1. Judge is a usable instrument

Judge's full-text hate read vs the gold `binary_label`:

| metric | value |
| --- | --- |
| agreement | **80.0%** |
| recall | 91.7% |
| precision | 82.2% |
| n | 963 |

The judge is not an arbitrary oracle — it agrees with the dataset's own labels 80%
of the time, with high recall.

## 2. Target recovery does NOT depend on the judge

Scoring each release's target against the **gold** HateXplain target groups
(synonym-mapped, e.g. judge "black people" == gold "african"), instead of against
the judge's full-text read:

| Variant | vs gold targets | (paper, vs judge read) |
| --- | ---: | ---: |
| Importance only | 36.7% | 35.5% |
| Window (r=2) | 46.9% | 52.1% |
| Window (r=3, matched) | 50.3% | 58.2% |
| **I-CEM** | **56.0%** | 67.3% |

McNemar I-CEM vs token-matched window: **p = 0.0003** (icem-only 90, matched-only 47).
McNemar I-CEM vs importance-only: p = 3e-21.

The I-CEM > matched-window ordering **replicates against gold and stays
significant**, so the target win is not judge self-agreement.

## 3. Hate fidelity does NOT survive the stricter gold test

Excerpt hate decision vs gold `binary_label` (paired, n=951):

| Variant | accuracy vs gold |
| --- | ---: |
| Importance only | 73.2% |
| Window (r=2) | 75.1% |
| Window (r=3, matched) | 76.6% |
| **I-CEM** | **78.1%** |

McNemar I-CEM vs matched window: **p = 0.11 (n.s.)**; vs importance-only: p = 2.4e-4.

Consistent with the borderline, judge-dependent fidelity margin (p=0.04 against the
judge, n.s. for 2/4 panel judges). Report the I-CEM-vs-wide-window fidelity edge as
**directional**, not confirmatory.

## 4. Caveat: do NOT anchor CS->Hate to gold

HateXplain gold labels do not encode stance: a post quoting/condemning a slur is
often labeled hateful/offensive. So gold-non-hate rows are not the counter-speech
set, and the dramatic 53%->24.5% corruption-and-recovery story (against the judge's
stance-aware full-text read) flattens against gold non-hate (60.2%->52.3%). The
judge's full-text stance read is the appropriate reference for the counter-speech
misread metric; gold is the appropriate reference for the *target* and *hate-label*
metrics. Each metric is anchored to the reference that actually encodes it.

## Bottom line

- Judge validated against gold (80% hate agreement) — sound instrument.
- **Target recovery: robust** — replicates against gold, significant (p=0.0003).
- **Hate fidelity over a wide matched window: directional** — n.s. against gold.
- Multiple-comparison discipline: treat as confirmatory only effects holding under
  both the judge and gold references (or across judges); single p-values near .05
  are directional.
